Respaldo de la Base de Datos

Genere una copia completa de la base de datos del sistema en formato .sql. El archivo se descargara a este equipo y tambien quedara guardado automaticamente en el servidor dentro de la carpeta backend/backups, para que pueda restaurarlo en caso de un problema.

Espere unos segundos, el tamano de la base de datos determina el tiempo de generacion.

Para restaurar una copia

Si el sistema presenta un problema, la restauracion se realiza desde la consola de MySQL con:
mysql -u root -p gestion_comunicacion_social < backup_archivo.sql
